# ذاكرة المشروع
## مؤكد من المستخدم
- يريد بدء قناة فعلية، ويهتم بالربحية والاستمرار.
- ينجذب إلى موضوع لا يبحث عنه عادة، لكن عرضه كمقترح يجعله يريد معرفة الإجابة.
- يريد معالجة أكبر وأعمق من غرائب الحياة اليومية الصغيرة.
- اختار قناة لوريستي @loristy224 مرجعًا للاتجاه.
- طلب فرز القناة وبناء مشروع GitHub وملفات Markdown للأسلوب والإنتاج والمونتاج والأبحاث والأصول والأخطاء.

## فهم تحريري مبدئي
مقالات فيديو قصصية تستكشف الإنسان عبر الأفلام والروايات: سؤال ذو صلة بالمشاهد، قصة تحمل الصراع، وتحليل أصلي له نتيجة. هذا توصيف مستنتج من العناوين المتاحة؛ ليس مشاهدة كاملة.

## لم يُحسم
اسم القناة، الفئة العمرية الفعلية، بلد صاحب القناة وبلدان الجمهور، الميزانية، الأدوات، الظهور بالوجه، صوت بشري أو بديل، اللهجة، وقت العمل الأسبوعي، مدة الحلقات، موعد الإطلاق.

## افتراضات قابلة للتعديل
اسم المستودع insan-story-lab؛ عام بتصريح المستخدم الأحدث. لهجة مصرية مبسطة في الأمثلة لمناسبة المرجع. فيديو طويل أساس التجربة وشورتس اختيارية للتعريف. لا قرار نهائي بالنشر أو التواتر.

## قرارات EP001 المؤكدة من المستخدم
- الشخصية: باتريك جين من The Mentalist.
- العنوان: «ليه مش كفاية إنك تكون أذكى واحد في المكان؟ | باتريك جين».
- اختيار أسلوب الإنتاج بمقارنة مرشحين ودراسته وتوثيقه قبل البحث العميق والسكريبت وجمع الأصول.
- ترند aura وصف المستخدم ولم يُتحقق منه مستقلًا. لا تقلبه إلى قياس مؤكد.

## تصحيح تفضيل الإنتاج
رفض المستخدم مرجع Like Stories of Old والأسلوب التأملي المعروض. يريد أسلوبًا وثائقيًا قويًا معروفًا عالميًا. اعتمد المستخدم لاحقًا MagnatesMedia مرجعًا للإنتاج الوثائقي وأذن ببدء البحث العميق.

## اعتماد الأسلوب والبحث والحرق
مرجع الإنتاج المعتمد MagnatesMedia؛ ليس تقليدًا حرفيًا ولا ادعاء دراسة مكتملة. المستخدم طلب بحثًا عميقًا وجمع أصول أثناءه. حسم الحرق: محدود دون تحذيرات داخل الفيديو. أُنجز بحث مكتبي ومقابلات مكتوبة وخرائط مشاهد وأصول فعلية، مع فصل الخلفية المتأخرة في BACKGROUND_SPOILERS وعدم تحميلها افتراضيًا للسكريبت.

## مرحلة الكتابة
طلب المستخدم البدء مباشرة بالنسخة النهائية. أُنجز script.md v1.0 ونص التسجيل المنفصل مع دليل إنتاج ومراجعة. لا اقتباسات من المقابلة غير المستمع إليها ولا تفاصيل خاتمة. تفضيل عدم حرق النتائج مستمر. اكتمال الكتابة لا يعني فحص الخام أو جاهزية النشر.

## التسجيل والمستودع
أفاد المستخدم بإكمال التسجيل بعد تعديل عبارتي الطفولة والأب وإضافة دعوة للاشتراك واقتراح الشخصية المقبلة. حُفظت التعديلات في script.md v1.1 وvoiceover-final.txt؛ لم يرفق تسجيلًا ولا ندعي فحصه.
المستودع الذي أنشأه المستخدم موجود في https://github.com/axasim7-debug/insan-story-lab وصلاحية دفع الملفات متاحة. ظهر عامًا عند الفحص؛ محاولة تحويله إلى خاص عبر التكامل رفضها GitHub 403. لا تُرفع الملفات حتى يتحقق أنه خاص وفق الإعداد المطلوب. الأصول الصغيرة نسبيًا ستدخل تاريخ Git مع النصوص، بدل فصلها في ZIP فقط.

## الإذن الأحدث للنشر العام
المستخدم طلب صراحة رفع المشروع والمستودع عام. هذا يلغي شرط انتظار تحويله إلى private. تُنشر الوثائق والسكريبت والذاكرة والصور المرخصة ولقطات المصادر والسجلات. سبعة ملفات كاملة مملوكة لأطراف أخرى (3 تسجيلات وملفا PDF ونسختا HTML لمقالتين) تبقى محليًا؛ توجد روابطها وأداة جمعها.
