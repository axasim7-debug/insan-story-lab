# مختبر الإنسان والحكاية
اسم عمل داخلي مؤقت؛ ليس الاسم النهائي للقناة.

مشروع تأسيس قناة عربية تقدم أسئلة إنسانية كبيرة عبر الأفلام والروايات والتحليل الأصلي. المرجع الذي اختاره المستخدم: https://www.youtube.com/@loristy224

## ابدأ هنا
1. اقرأ [START_HERE.md](START_HERE.md) لاستعادة السياق.
2. اقرأ [ذاكرة المشروع](memory/PROJECT_MEMORY.md) و[الحالة الحالية](memory/STATUS.md).
3. راجع [تحليل المرجع](research/REFERENCE_CHANNEL.md) وحدود الأدلة قبل نسبة أي سمة للقناة.
4. استخدم [سير الإنتاج](production/WORKFLOW.md) وقوالب الحلقة.

## خريطة الملفات
- `strategy/`: الاتجاه والجمهور والربحية وبنك الأفكار.
- `style/`: الصوت والكتابة والعناوين والمونتاج.
- `research/`: المراجع وعينة القناة ومنهج التحقق.
- `production/`: دورة العمل والقوالب والأصول والقياس.
- `episodes/`: ملفات الحلقات؛ أول حلقة تصور مبدئي فقط.
- `memory/`: القرارات والحالة والدروس وتحديثات الجلسات.
- `scripts/validate.py`: فحص سلامة الروابط المحلية ومعرفات المصادر.

لا تحتوي هذه النسخة على ملفات أفلام أو موسيقى أو فيديو منشور. لا توجد بيانات أرباح أو تحليلات خاصة بالقناة المرجعية. المستودع عام بإذن المستخدم، ويحتوي ملفات العمل قيد التطوير.

## الحلقة الأولى المعتمدة
[حزمة بحث باتريك جين](episodes/EP001/RESEARCH_INDEX.md): الموضوع والعنوان معتمدان، وMagnatesMedia مرجع إنتاج وثائقي. الحرق محدود دون تنبيهات بطلب المستخدم. تتضمن الحزمة بحثًا مكتبيًا وأصولًا محلية وسجلات تحقق؛ اكتملت كتابة السكريبت v1.1، ومطابقة المشاهد وتوقيتها لم تكتمل.

[السكريبت النهائي للحلقة الأولى](episodes/EP001/script.md) · [نص التسجيل](episodes/EP001/voiceover-final.txt).

التعليق الصوتي: المستخدم أفاد بإكمال التسجيل؛ لم يُرفق الملف بعد. الصور المرخصة ولقطات المصادر مشمولة في Git؛ النسخ المرجعية الكاملة موصوفة في السجلات وتبقى محليًا.

## الأصول في النسخة العامة
تشمل الصور المرخصة ولقطات المصادر والسجلات. لا تشمل التسجيلات المرجعية الكاملة أو ملفي الأبحاث PDF أو نسختي HTML الكاملتين للمقالتين؛ روابط المصادر والبصمات وأداة `scripts/collect_ep001_assets.py` محفوظة لإعادة جمعها للبحث المحلي. راجع [سياسة حفظ النسخ البحثية](PUBLIC_ASSETS.md).
