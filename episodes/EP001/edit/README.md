# بدء إنتاج EP001

## المنجز
- افتتاحية أصلية متحركة مدتها 24 ثانية، بدقة 1920×1080 ومعدل 24 إطارًا/ثانية.
- ملف `opening.html` يحمل الرسوم والحركة بشكل قابل للتعديل؛ `render-opening.cjs` يصدر MP4 عبر Chromium وFFmpeg.
- الصورة المستخدمة للممثل من S021 برخصة CC BY 2.0، مع نسب داخل المعاينة. ليست لقطة من أحداث المسلسل، وموضّح أنها خلف الكواليس.
- التوقيت حاليًا بصري تجريبي؛ هذه ليست مزامنة مع التعليق أو افتتاحية نهائية للفيديو الطويل.

## عائق الصوت
أرفق المستخدم `merged-enhanced-v2.wav` عبر المحادثة. أداة download_file رفضت النقل لأنه يتجاوز حد 32 MiB. لم يتوفر مسار محلي، ولا توجد مدة أو جودة أو مطابقة كلام مفحوصة. طُلبت نسخة MP3 192 kbps أو M4A، مع الاحتفاظ بالـWAV الأصلي للماستر. لا ادعاء استماع أو استخراج waveform.

## إعادة التصيير
المعاينة السريعة: `python episodes/EP001/edit/render-preview.py --refresh-boards`.
للتصيير إطارًا بإطار للحركة الأصلية (أبطأ): `node episodes/EP001/edit/render-opening.cjs`.
لتصدير اللوحات فقط: `node episodes/EP001/edit/render-opening.cjs --boards-only`.
يتطلب Node + Playwright، Chromium في `/usr/bin/chromium`، وFFmpeg مع libx264، وخطوط Noto Arabic النظامية. الخادم المستخدم محلي فقط؛ لا رفع خارجي أثناء التصيير.
المخرجات: `exports/EP001/opening-visual-v1.mp4` وأربع صور معاينة. exports مستبعد من Git.

## المرحلة التالية عند وصول الصوت
1. تنزيله وفحص المدة والقنوات والذروة وقياس جهارة الصوت.
2. تقسيم التسجيل وفق الفصول الفعلية وتسجيل مواضع الانتقال المسموعة.
3. مزامنة الافتتاحية مع أول الفقرات، وتغيير مددها أو لقطاتها بحسب الأداء.
4. تركيب بقية الحجة بمشاهد متحقق منها ورسوم أصلية، دون تحويل الحلقة إلى شرائح عناوين متكررة.
5. تصدير نسخة مشاهدة كاملة ثم مراجعتها بصريًا وصوتيًا.

## ملاحظات المعاينة
لا صوت أو موسيقى أو تسجيلات مقابلات في هذه النسخة. لا نتائج قضايا أو نهايات أو هوية ريد جون. بطاقات الملاحظة والاستنتاج قراءة تحريرية عامة وليست وصفًا علميًا لإحدى حيل المسلسل.
