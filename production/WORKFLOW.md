# دورة إنتاج الحلقة
الحالات: فكرة → بحث → مخطط → سكريبت → صوت → مونتاج أول → مراجعة → جاهز → منشور → تحليل.

| المرحلة | المخرج المطلوب | شرط الانتقال |
|---|---|---|
| اختيار الفكرة | brief.md | سؤال واضح وقيمة أصلية وقدرة إنتاج مبدئية |
| البحث | research.md + المصادر | شواهد القصة والادعاءات والاعتراضات موثقة |
| المخطط | outline.md | تصاعد وتحول وجواب للوعد |
| الكتابة | script.md | إلقاء مفهوم وفصل الرأي عن الحقيقة |
| الأصول | storyboard.csv + السجل | لكل أصل مصدر وحالة استخدام وبديل |
| الصوت | voice-notes.md | عينة مفهومة وتقدير مدة وقرار أسلوب |
| المونتاج | review.md | قصة مفهومة وصوت واضح وأصول صالحة |
| قبل النشر | packaging.md + قائمة الفحص | حرق واضح عند الحاجة، مصادر، وصف وتغليف صادق |
| بعد النشر | metrics.csv + retrospective.md | قياس 48 ساعة و7 و28 يومًا إن توفرت البيانات |

لا نشر حاليًا؛ إنشاء ملفات الإنتاج لا يساوي تفويض نشر على يوتيوب.

## توقيت تجريبي يعتمد على موارد المستخدم
قسّم العمل على مراحل لا على وعد أسبوعي: اختيار وبحث؛ كتابة ومراجعة؛ تسجيل؛ مونتاج؛ فحص. بعد أول حلقة احسب ساعات كل مرحلة قبل إعلان جدول ثابت.

## شروط الجاهزية
- إجابة حقيقية لسؤال العنوان وإضافة أصلية.
- لا ادعاءات مجهولة المصدر تُقدَّم كحقائق.
- لا أصول مجهولة الترخيص تُعامل كمرخصة.
- مشاهدة التصدير كاملًا وتسجيل الإصلاحات.
- حفظ نسخة السكريبت والمشروع وسجل الأصول والتكاليف.
