# جمع الأصول وحفظها
الأولوية: تصوير وصوت ورسوم أصلية، ثم مواد برخصة مناسبة، ثم استخدامات نقدية محددة تُراجع حسب السياق. لا تنزيل شامل لأعمال أو إعادة استخدام أصول القناة المرجعية.

## أين تحفظ الملفات؟
Git: نصوص وسجلات وملاحظات وملفات إعداد صغيرة.
تخزين أصول يحدده المستخدم لاحقًا: خامات فيديو وصوت ومشاريع التحرير الثقيلة ونسخ التصدير. سجّل المسار ومعرّف الملف والبصمة SHA256 عند الاستلام. لا نفترض أن مسار جهاز قديم سيعمل في شات جديد.

## لكل أصل
asset_id، الحلقة، الوصف، الرابط الأصلي، المالك، نوع الترخيص، رابط الإثبات أو الملف، تاريخ الاطلاع، شروط النسب، الاستخدام المقصود، قرار الاستخدام، المسار، البصمة، البديل. القالب ASSET_REGISTER.csv.

الحالات: مقترح / يحتاج ترخيص / مرخص مع شروط / من إنتاجنا / قيد مراجعة استخدام نقدي / مستبعد.
ذكر المصدر لا يساوي الترخيص. لا مدة قصيرة آمنة تلقائيًا. احتفظ بدليل رخصة الموسيقى وقت التحميل، وبنسخة بديلة عند المطالبات.

## استثناء EP001 الحالي
بناءً على طلب المستخدم حفظ مجلد المشروع كاملًا: تُدرج أصول البحث المجموعة الحالية (نحو 71 ميجابايت، وكل ملف أقل من 23 ميجابايت) مباشرة في Git داخل المستودع الخاص، مع سجلات الحقوق والبصمات. خامات الفيديو أو المشاريع الثقيلة المستقبلية ما زالت تحتاج اختيار تخزين مناسب لحجمها. التسجيل الصوتي الشخصي للمستخدم لم يُرفق بعد.

## تحديث النشر العام — يتقدم على استثناء المستودع الخاص
المستودع أصبح عامًا بإذن المستخدم. تُنشر الصور المرخصة ولقطات المصادر والسجلات، بينما تبقى التسجيلات والمقالات الكاملة للبحث المحلي وفق PUBLIC_ASSETS.md. ملف تسجيل المستخدم نفسه لم يُرفق بعد.
